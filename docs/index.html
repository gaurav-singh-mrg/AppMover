AppMover
Features Safety Install Support

Free up your Mac's startup disk without deleting anything.

AppMover moves app data onto an external drive and leaves a link behind, so your apps keep finding it. Changed your mind? Undo puts everything back.

Download for Mac View on GitHub

Requires macOS 14 Sonoma or later and an external drive.

See what's taking space, then move it

AppMover lists the apps whose data is filling your startup disk, biggest first, and moves it with one click.

One row per app

Application Support, Caches and Developer data for each app together, with every folder and its size one click away.

Undo any time

The Moved tab lists everything on the drive, each with a button to put it back where it came from.

Any connected drive

Send an app to whichever drive you like, or split it up: its Caches on one drive, its Application Support on another.

Warns about slow drives

Each drive gets a quick speed test the first time it's connected. If you pick a slow one, AppMover tells you before moving.

Real progress

The progress bar counts bytes as they're copied, so it shows how far along the move really is.

In your language

Nothing is deleted until the copy checks out

Every move follows the same steps. If one fails, your original goes back in place and the partial copy is removed.

  1. CopyThe folder is copied to the drive.
  2. CheckEvery file and every byte is counted on both sides.
  3. Set asideThe original is renamed, not deleted.
  4. LinkA link to the copy takes the folder's place.
  5. Check againAppMover makes sure the link opens the copy.
  6. Clean upOnly now is the original removed.

Good to know

A moved folder behaves a little differently. AppMover reminds you before each move.

Keep the drive connected

While it's unplugged, an app can't reach the data you moved. Nothing is written to your Mac in the meantime, so your data never ends up split in two.

Time Machine skips moved folders

Time Machine doesn't follow links, so moved folders drop out of your backups. Keep another copy of anything you can't download again.

Some folders stay put

macOS's own folders and sandboxed app containers aren't offered, because moving them would break the apps that use them.

Install

AppMover isn't notarized by Apple yet, so macOS asks you to confirm the first time you open it.

  1. DownloadGet the zip from the latest release, open it, and move AppMover to your Applications folder.
  2. Open it once, then allow itmacOS blocks the first launch. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway.
  3. Choose your driveClick the gear in AppMover's top bar and pick the drive and folder to move data to.
  4. Grant Full Disk Access if askedIf AppMover says “Can't read your Library”, click Open Privacy Settings, turn on AppMover under Full Disk Access, then quit and reopen it.

AppMover checks GitHub for new versions when its window opens and shows a Download button when one is out. It never installs anything by itself.
